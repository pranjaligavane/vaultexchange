Vault Exchange

Send a file to someone whose public key you have, without ever putting the file's contents at risk on the wire. The file itself is locked with a fresh symmetric key; only that small key is locked with RSA.

RSA-OAEP 2048 · AES-256-GCM · runs entirely in your browser

1. Key pair

1

Generate your RSA key pair

The private key never leaves this page. Share only the public key with whoever will send you files.

2. Encrypt a file

2

Lock a file for a recipient

Paste the recipient's public key, choose a file. A random AES-256 key encrypts the file; that key is then wrapped with the recipient's RSA public key.

3. Decrypt a file

3

Unlock a file sent to you

Your RSA private key unwraps the AES key, which is then used to decrypt the file's contents.

Nothing here is transmitted anywhere — key generation, wrapping, and encryption all happen locally via the browser's Web Crypto API. Closing this tab discards everything except what you've downloaded.
